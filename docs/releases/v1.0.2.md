# AI 速览 1.0.2

基于 [AIHOT](https://aihot.news/) 网站的非官方 Android 阅读器。资讯直接来自原站，联网打开或刷新即可更新。

- 状态栏和底部系统区域接续网页背景，保留系统时间、电量和手势条。
- 原生菜单、错误提示及刷新指示跟随网页深浅主题；补齐无触摸主题变化的颜色同步。
- 保留下拉刷新、长按菜单、搜索、收藏、分享和站外浏览器跳转。
- 配色未变化时跳过重复更新。

## 安装

下载 `aihot-reader-1.0.2.apk`。最低安装系统 Android 8.0，需要能够正常运行 AIHOT 的较新 WebView。已有同签名 1.0.0/1.0.1 时直接覆盖安装，保留收藏，不要先卸载。

`versionCode=4`；包名 `dev.personal.aihotreader`。

APK SHA-256：`bc51cb74a43f34823a83ed05b9204df42182b60e94ffabc9e3cb4bbd1d21da2d`。

## 验证与边界

Android 16 / WebView 133 模拟器已验证阅读、搜索、收藏升级保留、阅读位置恢复、键盘、深浅主题、挖孔、横屏及断网重试。Android 8 / WebView 69 仅通过原生布局检查，该旧内核不能完整运行当前网站。实体手机及 WebView 144 以上环境尚未实测，详见 `VALIDATION.md`。
