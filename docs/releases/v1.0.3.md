# AI 热点 1.0.3

基于 [AIHOT](https://aihot.news/) 网站的非官方 Android 阅读器，原名「AI 速览」。资讯直接来自原站，联网打开或刷新即可更新。

本次仅将应用名称改为「AI 热点」。沿用 AIHOT Logo，保留全面屏适配、深浅主题、下拉刷新、长按菜单、搜索、收藏与分享等现有功能。

## 安装与升级

下载 `aihot-reader-1.0.3.apk`。最低安装系统 Android 8.0，需要能够正常运行 AIHOT 的较新 WebView。已有同签名的 1.0.0、1.0.1 或 1.0.2 时直接覆盖安装，不要先卸载。

`versionCode=5`；包名仍为 `dev.personal.aihotreader`，发布签名不变，覆盖升级可保留应用内收藏。

APK SHA-256：`0f04db911a31dbf0adb852afea00ef26218bec0156ba7756889dc845de7e9b8d`。

## 验证记录

本次构建、签名及名称检查以 [VALIDATION.md](https://github.com/BH0001/aihot-android/blob/v1.0.3/VALIDATION.md) 中的 1.0.3 记录为准。1.0.2 的完整功能测试保留为历史证据，不计作 1.0.3 的全量运行回归。

此前 Android 16 / WebView 133 模拟器已验证主要阅读功能。Android 8 / WebView 69 仅通过原生布局检查，该旧内核不能完整运行当前网站。实体手机及 WebView 144 以上环境尚未实测。
